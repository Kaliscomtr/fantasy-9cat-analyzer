A personal, non-commercial analytics project for Yahoo Fantasy Basketball head-to-head nine-category leagues.

Designed to turn roster statistics, matchups, and available-player data into practical, explainable fantasy decisions.

Planned capabilities

01 / Roster intelligence

Compare team strengths and weaknesses across FG%, FT%, 3PTM, PTS, REB, AST, STL, BLK and TO.

02 / Matchup planning

Review weekly matchups and identify categories worth prioritizing.

03 / Waiver opportunities

Evaluate available players based on team needs, roles and statistical contributions.

04 / Trade evaluation

Explore potential roster improvements through category-based comparisons.

Yahoo Fantasy data usage

Subject to API approval and availability, the project intends to request read-only access to the owner's fantasy basketball league settings, rosters, player statistics, available-player listings, matchups, standings and transaction history. The initial scope is two leagues managed by one user.

Privacy & access

  • Personal use only; not a commercial product or public fantasy service.
  • No automated adds, drops, trades or other write operations.
  • No public display of private league data or OAuth credentials.
  • OAuth credentials and tokens will not be stored in this public GitHub Pages repository.
  • API usage will follow applicable Yahoo policies and permissions.

Project status

This is an early-stage project description for developer API access review. The analytics application and Yahoo account integration are not yet operational. This website is informational only and does not request login credentials.
